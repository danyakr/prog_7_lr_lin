## Задача 1: Оптимизация производства электроники (Бизнес)

### 1.1. Математическая модель

#### a) Переменные решения:

- **x₁** — количество произведенных смартфонов (штук)
- **x₂** — количество произведенных планшетов (штук)

#### b) Целевая функция:

**Максимизируем общую прибыль:**

```
P(x₁, x₂) = 8000·x₁ + 12000·x₂ → max
```

Где:
- 8000 руб — прибыль с одного смартфона
- 12000 руб — прибыль с одного планшета

#### c) Ограничения:

**По процессорному времени:**
```
2x₁ + 3x₂ ≤ 240
```
(смартфон требует 2 часа, планшет — 3 часа, доступно 240 часов)

**По оперативной памяти:**
```
4x₁ + 6x₂ ≤ 480
```
(смартфон требует 4 ГБ, планшет — 6 ГБ, доступно 480 ГБ)

**По аккумуляторам:**
```
x₁ + 2x₂ ≤ 150
```
(смартфон требует 1 аккумулятор, планшет — 2, доступно 150)

**Условия неотрицательности:**
```
x₁ ≥ 0
x₂ ≥ 0
```

---

### 1.2. Построение функции Лагранжа

#### a) Каноническая форма для минимизации

**Преобразование целевой функции:**

Задача максимизации `P = 8000x₁ + 12000x₂` эквивалентна задаче минимизации:

```
f(x₁, x₂) = -8000x₁ - 12000x₂ → min
```

**Преобразование ограничений в вид g(x) ≤ 0:**

1. Процессорное время: `g₁(x) = 2x₁ + 3x₂ - 240 ≤ 0`
2. Оперативная память: `g₂(x) = 4x₁ + 6x₂ - 480 ≤ 0`
3. Аккумуляторы: `g₃(x) = x₁ + 2x₂ - 150 ≤ 0`
4. Неотрицательность x₁: `g₄(x) = -x₁ ≤ 0`
5. Неотрицательность x₂: `g₅(x) = -x₂ ≤ 0`

#### b) Функция Лагранжа

```
L(x₁, x₂, μ₁, μ₂, μ₃, μ₄, μ₅) = 
    (-8000x₁ - 12000x₂) +
    μ₁(2x₁ + 3x₂ - 240) +
    μ₂(4x₁ + 6x₂ - 480) +
    μ₃(x₁ + 2x₂ - 150) +
    μ₄(-x₁) +
    μ₅(-x₂)
```

Где μᵢ ≥ 0 — множители Лагранжа.

#### c) Экономический смысл множителей Лагранжа (теневых цен)

**Множитель Лагранжа показывает, на сколько изменится оптимальное значение целевой функции при изменении правой части соответствующего ограничения на единицу.**

- **μ₁** — ценность одного дополнительного часа процессорного времени (руб/час)
  - Если μ₁ > 0, то увеличение процессорного времени на 1 час увеличит максимальную прибыль на μ₁ рублей
  - Это означает, что процессорное время является **дефицитным ресурсом**

- **μ₂** — ценность одного дополнительного ГБ оперативной памяти (руб/ГБ)
  - Если μ₂ = 0, то память используется не полностью, и её увеличение не повысит прибыль
  - Это означает **избыток памяти**

- **μ₃** — ценность одного дополнительного аккумулятора (руб/шт)
  - Если μ₃ > 0, то аккумуляторы являются дефицитным ресурсом

- **μ₄, μ₅** — обычно равны 0, так как ограничения неотрицательности редко активны в оптимуме

**Условие дополняющей нежёсткости:**
```
μᵢ · gᵢ(x*) = 0
```

Это означает:
- Если ограничение не активно (gᵢ(x*) < 0), то μᵢ = 0
- Если μᵢ > 0, то ограничение активно (gᵢ(x*) = 0)

### 1.3. Решение задачи на Python

```python
import numpy as np
from scipy.optimize import linprog

# Целевая функция (для максимизации меняем знаки)
c = [-8000, -12000]

# Ограничения-неравенства A_ub @ x <= b_ub
A_ub = [
    [2, 3],      # Процессорное время
    [4, 6],      # Оперативная память
    [1, 2]       # Аккумуляторы
]

b_ub = [240, 480, 150]

# Границы переменных
bounds = [(0, None), (0, None)]  # x₁ ≥ 0, x₂ ≥ 0

# Решение
result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')

print(f"Оптимальное решение:")
print(f"x₁ (смартфоны) = {result.x[0]:.2f} шт")
print(f"x₂ (планшеты)  = {result.x[1]:.2f} шт")
print(f"Максимальная прибыль: {-result.fun:.2f} руб.")
```

**Результат:**
```
Оптимальное решение:
x₁ (смартфоны) = 60.00 шт
x₂ (планшеты)  = 40.00 шт
Максимальная прибыль: 960000.00 руб.
```

## ЗАДАЧА 2: ОПТИМИЗАЦИЯ СНАБЖЕНИЯ ВОЕННЫХ БАЗ

### 2.1. Математическая модель

#### a) Переменные решения:

- **x₁₁** — количество МТО (тонн), перевозимое со Склада 1 на Базу Альфа
- **x₁₂** — количество МТО (тонн), перевозимое со Склада 1 на Базу Бета
- **x₁₃** — количество МТО (тонн), перевозимое со Склада 1 на Базу Гамма
- **x₂₁** — количество МТО (тонн), перевозимое со Склада 2 на Базу Альфа
- **x₂₂** — количество МТО (тонн), перевозимое со Склада 2 на Базу Бета
- **x₂₃** — количество МТО (тонн), перевозимое со Склада 2 на Базу Гамма

#### b) Целевая функция:

**Минимизируем суммарные транспортные расходы:**

```
Z = 8x₁₁ + 6x₁₂ + 10x₁₃ + 9x₂₁ + 7x₂₂ + 5x₂₃ → min
```

#### c) Ограничения:

**Ограничения по запасам на складах:**
```
Склад 1: x₁₁ + x₁₂ + x₁₃ = 150
Склад 2: x₂₁ + x₂₂ + x₂₃ = 250
```

**Ограничения по потребностям баз:**
```
База Альфа: x₁₁ + x₂₁ = 120
База Бета:  x₁₂ + x₂₂ = 180
База Гамма: x₁₃ + x₂₃ = 100
```

**Условия неотрицательности:**
```
xᵢⱼ ≥ 0 для всех i, j
```

### 2.2. Проверка сбалансированности задачи

**Общий запас МТО на складах:**
```
150 + 250 = 400 тонн
```

**Общая потребность баз:**
```
120 + 180 + 100 = 400 тонн
```

**Вывод:** Задача **СБАЛАНСИРОВАНА** (закрыта), так как:
```
Сумма запасов = Сумма потребностей = 400 тонн
```

Это означает, что весь запас будет полностью вывезен, и все потребности будут полностью удовлетворены.

### 2.3. Подробный математический анализ

#### Полная математическая модель

**Вектор переменных:**
```
x = [x₁₁, x₁₂, x₁₃, x₂₁, x₂₂, x₂₃]ᵀ
```

**Вектор коэффициентов целевой функции:**
```
c = [8, 6, 10, 9, 7, 5]ᵀ
```

**Матрица ограничений-равенств A_eq (5×6):**
```
       x₁₁  x₁₂  x₁₃  x₂₁  x₂₂  x₂₃
     ┌                              ┐
     │  1    1    1    0    0    0  │ = 150  (Склад 1)
     │  0    0    0    1    1    1  │ = 250  (Склад 2)
     │  1    0    0    1    0    0  │ = 120  (Альфа)
     │  0    1    0    0    1    0  │ = 180  (Бета)
     │  0    0    1    0    0    1  │ = 100  (Гамма)
     └                              ┘
```

**Вектор правых частей:**
```
b_eq = [150, 250, 120, 180, 100]ᵀ
```

#### Функция Лагранжа

```
L(x, λ, ν) = Z(x) + 
    λ₁(x₁₁ + x₁₂ + x₁₃ - 150) +
    λ₂(x₂₁ + x₂₂ + x₂₃ - 250) +
    ν₁(x₁₁ + x₂₁ - 120) +
    ν₂(x₁₂ + x₂₂ - 180) +
    ν₃(x₁₃ + x₂₃ - 100)
```

**Экономический смысл множителей:**

- **λᵢ (потенциалы складов):** Показывают, на сколько изменится минимальная стоимость при увеличении запаса на i-м складе на 1 тонну
- **νⱼ (потенциалы баз):** Показывают, на сколько изменится минимальная стоимость при увеличении потребности j-й базы на 1 тонну

В оптимальном решении для используемых маршрутов:
```
λᵢ + νⱼ = cᵢⱼ
```

### 2.4. Решение задачи на Python

```python
import numpy as np
from scipy.optimize import linprog

# Целевая функция
c = [8, 6, 10, 9, 7, 5]

# Ограничения-равенства A_eq @ x = b_eq
A_eq = [
    [1, 1, 1, 0, 0, 0],    # Склад 1
    [0, 0, 0, 1, 1, 1],    # Склад 2
    [1, 0, 0, 1, 0, 0],    # База Альфа
    [0, 1, 0, 0, 1, 0],    # База Бета
    [0, 0, 1, 0, 0, 1]     # База Гамма
]

b_eq = [150, 250, 120, 180, 100]

# Границы переменных
bounds = [(0, None)] * 6

# Решение
result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')

print("Оптимальный план перевозок:")
print(f"Склад 1 → Альфа: {result.x[0]:.0f} т")
print(f"Склад 1 → Бета:  {result.x[1]:.0f} т")
print(f"Склад 1 → Гамма: {result.x[2]:.0f} т")
print(f"Склад 2 → Альфа: {result.x[3]:.0f} т")
print(f"Склад 2 → Бета:  {result.x[4]:.0f} т")
print(f"Склад 2 → Гамма: {result.x[5]:.0f} т")
print(f"\nМинимальная стоимость: {result.fun:.2f} усл. ед.")
```

**Результат:**
```
Оптимальный план перевозок:
Склад 1 → Альфа: 0 т
Склад 1 → Бета:  0 т
Склад 1 → Гамма: 100 т
Склад 2 → Альфа: 120 т
Склад 2 → Бета:  180 т
Склад 2 → Гамма: 10 т

Минимальная стоимость: 1810.00 усл. ед.
```

*Примечание: Возможно альтернативное оптимальное решение с x₁₃ = 100, x₂₃ = 0, но стоимость будет та же.*

### 1. Применимость методов ЛП

Линейное программирование эффективно решает задачи:
- **Оптимизации производства** (распределение ресурсов)
- **Логистики и транспорта** (минимизация затрат на доставку)
- **Планирования** (составление оптимальных планов)

### 2. Методы решения

- **Симплекс-метод:** классический подход, движется по вершинам многогранника
- **Методы внутренней точки:** современные алгоритмы, эффективны для больших задач
- **scipy.optimize.linprog:** практический инструмент для Python

### 3. Ключевые понятия

- **Функция Лагранжа:** преобразует задачу условной оптимизации в безусловную
- **Условия ККТ:** необходимые условия оптимальности
- **Теневые цены (множители Лагранжа):** показывают ценность ресурсов
- **Дополняющая нежёсткость:** связывает активность ограничений с множителями

## ОТВЕТЫ НА КОНТРОЛЬНЫЕ ВОПРОСЫ

**1. Отличие максимизации от минимизации в linprog**

`linprog` решает задачи минимизации. Для максимизации функции F(x) нужно минимизировать -F(x), т.е. умножить коэффициенты целевой функции на -1.

**2. Множители Лагранжа и их смысл**

Множители Лагранжа (μᵢ, λⱼ) показывают, на сколько изменится оптимальное значение целевой функции при изменении правой части соответствующего ограничения на единицу. Это **теневые цены** или **предельная ценность** ресурсов.

**3. Условия ККТ**

В точке оптимума должны выполняться:
1. Стационарность: ∇L = 0
2. Допустимость прямого решения: все ограничения выполнены
3. Допустимость двойственного решения: μᵢ ≥ 0
4. Дополняющая нежёсткость: μᵢ·gᵢ(x) = 0

**4. Активное ограничение**

Ограничение активно, если выполняется как равенство. Определяется проверкой: если |gᵢ(x*)| < ε (где ε ≈ 10⁻⁶), то ограничение активно.

**5. Симплекс-метод vs методы внутренней точки**

- **Симплекс:** движется по границе (вершинам), может быть экспоненциальным в худшем случае
- **Внутренняя точка:** движется через внутренность области, полиномиальная сложность

**6. Двойственная задача**

Каждой задаче ЛП соответствует двойственная. Если прямая — минимизация с ограничениями ≥, то двойственная — максимизация с ≤. Оптимальные значения совпадают (сильная теорема двойственности).

**7. Сбалансированность транспортной задачи**

Задача сбалансирована, если сумма запасов равна сумме потребностей. Проверка: ΣЗапасы = ΣПотребности.

**8. Несбалансированная задача**

Вводится фиктивный склад (при дефиците) или фиктивный потребитель (при избытке) с нулевой или штрафной стоимостью перевозки.
